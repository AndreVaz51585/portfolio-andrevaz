Final Project Platform

EvoLabAsAService

One of my largest projects: a platform for managing experimental projects with a Spring Boot + Kotlin backend and a React + TypeScript frontend. It connects authentication, job orchestration, Docker execution, AI validation, and chatbot support.

The backend includes a pool of workers that consume experimental projects from a Channel, launch OpenEvolve containers using the docker-java library, and persist job state in the database.

Kotlin Spring Boot React TypeScript docker-java OAuth 2.0 PostgreSQL
  • Worker pool consuming projects from a Kotlin Channel
  • Launches OpenEvolve containers with docker-java
  • OAuth 2.0 authentication and persisted job tracking
  • Chatbot integration with OpenAI, Gemini and local model credential validation
